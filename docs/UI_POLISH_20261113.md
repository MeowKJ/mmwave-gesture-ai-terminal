# 460×460 小屏交互修订

日期：2026-11-13。仅产品 UI、图标、键盘和音频反馈；不刷写/复位 C5，不更改显示初始化、旋转、触摸、电源保持或 USB 下载链路。

## 本轮目标与实现

| 用户问题 | 处理 |
| --- | --- |
| 两处“扫描中” | 单一状态呈现函数；进度出现时隐藏连接状态/网络计数，空列表引导也不重复出现。按钮始终为“扫描”，请求一被接受即禁用，避免状态轮询前重复提交。进度由真实完成事件结束，不自行到时消失。 |
| 信号缺单位 | 网络列表每条显示 `-xx dBm`，与网络名同一基线、右侧同一列。 |
| 图标不精致/缺失 | 引入 **Lucide 0.468.0** 真正的 SVG 子集，保留 ISC 原文、源码和 SHA-256。按各自实际尺寸四倍超采样，生成原生 A8 遮罩，不把小图放大、不依赖图标字体。眼睛/呼吸的产品标记不替换为通用图标。 |
| 扬声器试听 | 使用 **Kenney Music Jingles / jingles_PIZZI07** 的 CC0 拨弦音乐（约 1.32 秒，另有 100ms 静音尾部），替换自行合成的测试旋律。源 Ogg、许可、哈希和生成脚本均在仓库。保持当前系统音量及静音，不重设试听音量。 |
| 交互“咚”与开关 | 原创 120ms 确认声，2ms 起音、二次衰减至零；辅助功能明确标为“交互音效”，保存到现有 NVS。GUI 只排队；关闭/静音后丢弃待播提示，不抢占试听/自检。R2 用户仍未听到，不能以驱动返回成功关闭目标。 |
| 麦克风设置行 | 保留“麦克风”，右侧只显示百分比，不再重复写“灵敏度”；子页使用图标、大百分比与滑杆。数值仍与实际 PGA 及设置保存共用同一数据源。R2 实屏已获用户确认。 |
| Wi-Fi 排版 | R2 改为统一暗蓝黑面板、细分隔线、Lucide 信号图标，不再使用四个厚重灰色胶囊。网络名/连接状态及 dBm 共用左右列；保留 316px 视口、一屏四条完整 72px 触摸目标。R2 实屏已获用户确认。 |
| 小设备输入法 | 熟悉的三列数字/字母大键盘，132×64px；小写/大写/数字/全部 ASCII 符号可切换，显示/删除独立 64px 按钮、连接独立放置。组合中的字母短暂可见，700ms 后遮蔽；“下一位”立即提交组合，重复字母不必等超时。根据实际文字宽度保留末尾，不固定截取字符数。 |

## 验证分层

1. **桌面渲染**：使用生产 LVGL 页面，不是另一套 HTML；检查实际字形、28/44px 字号、图标像素、边界和状态列对齐。
2. **软件触摸**：180° 原始坐标输入，验证列表滚动/防误触、每个键盘区、模式切换、退格、重复字母、密码保留/清空、64 字节上限和交互音开关。扫描中至少 21 秒仍只显示一个进度，在线扫描不同时显示“已接入”。
3. **音频软件**：生产音频路径、互斥所有权、静音/失败处理；音乐样本分块一致、峰值/时长/静音尾部，提示声首尾为零且不越界。源资产校验离线运行。
4. **固件构建**：最终 ELF 必须包含生产 UI，并通过现有 Wi-Fi 结构 ABI 检查。不把成功编译当作屏幕/声学验收。
5. **实屏/听感**：用户重插 USB 后，首版和 R2 均已烧录校验并自动启动。首版无花屏、R2 网络/麦克风视觉获确认；R2 交互音仍无声。显示、音频驱动返回和真实听感分别验收。

桌面快照、测试报告位于忽略目录 `test-results/ui-polish-20261113/`；最终结果在完成复测后记录于本节。

### 首次 USB 失败（历史，重插后已恢复）

- 原生 USB 应用态 COM10（303A:4005）进入 ROM COM9（303A:0012）后，串口配置报 WinError 121；未进入写入校验。
- 只读 chip-id 同样超时；精确设备重新枚举输出 Access denied，尽管命令返回 0，仍记失败。
- 证据保留 `usb-acceptance-01.json`、`hardware-acceptance-01.log`、`rom-probe-01.json`、`usb-host-reenumerate-01.log`。
- 用户只重插了原生 USB；后续成功不抹去前述失败，也不代表 Windows 下载故障已根治。

### R3：功放启动时序（已烧录，待听感确认）

- NS4150B 厂商规格书（Mar. 2021 V1.1，第 7 节）给出 Tst 典型 120ms；代码仅等待 25ms。
- 120ms 衰减提示音会与功放启动重叠，是明确的时序缺陷；是否为本板无声的完整根因仍须听感验证，不能只凭规格推断确认修复。
- 改为 150ms 唤醒等待，保持波形、用户音量、已验证 GPIO/I2S 时钟/DMA 和显示初始化不变。等待在现有 app/工程任务，不运行在 LVGL 回调；本轮未引入新的音频工作线程。
- 新增真实 BSP 提示音执行前的启动等待断言：旧 25ms 版本失败（`ctest-r3-red.log`），修订后相关音频三项通过（`ctest-r3.log`）。不删除或绕过失败证据。
- 生产构建增量 9 步成功，未 clean。ELF：`fcb9d12a1cab3c23e539ca09d18fb898a124083731fe65c34e0083efe38904e0`；bin SHA-256：`e949b1a6ab1b6c5d5ead68250952c8abd1b6cb6a62de13928223c31b36acab40`。
- `usb-acceptance-r3.json`：三段 Hash、P4 自动启动及 1 次程序复位通过，USB/电源保持/运行身份正常，未操作 C5。
- `cue-acceptance-r3.json`：按设备当时已有的 100% 音量与启用状态，播放一声提示音及一次 UI 音乐；两条驱动路径成功、codec 读回正确、同一 P4 boot。未修改音量或启用开关。
