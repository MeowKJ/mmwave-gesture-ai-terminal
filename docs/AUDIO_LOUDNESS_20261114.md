# 试听音乐低音量检查（2026-11-14）

## 结论与边界

- 用户此前报告音乐无声，2026-11-14 两次 100% 实测后明确为「音乐能听到，但很小」。不能继续将现象定性为完全无输出，也不能仅凭驱动返回成功认定响度正常。
- 查到一个明确的低电平因素：旧素材生成器把峰值固定到 7000，16-bit 满幅为 32767。即使产品音量 100%、DAC 读回 BF/BF，素材本身仍留下约 13.4 dB 的采样余量。
- 此因素可以修正，但不等于证明硬件增益、扬声器供电或所有音频场景均没有问题；没有测量声压／输出电压，首轮 30% 无语音的原因仍不下定论。

## 最小修订

- 只把同一首已锁定来源的 CC0 拨弦音乐重新定标为峰值 22000；24 kHz PCM RMS 从约 1833.5 提至 5762.4，数字电平约 +9.95 dB，保留约 3.46 dB 采样余量。
- 48 kHz 实际 renderer 输出峰值 22000、RMS 5757.3，没有满幅削波样本；立体声同相、插值、10 ms 两端淡变、末尾 100 ms 静音及播放长度不变。不把数字 dB 当成实测声压提升。
- 不改 ES8389／功放寄存器、系统音量曲线、音频引脚、单端麦克风、DMA 配置、语音 fixture、显示初始化、180° 旋转、电源保持或 C5。
- 生成器拒绝空白／非有限素材，生成 manifest 的 PCM SHA-256、采样率、帧数、峰值、RMS 和实际依赖版本；普通编译仍不依赖音频生成包或网络。

## 本轮证据

证据根目录：`test-results/music-silence-20261114`，全部留在本地 Git 忽略目录。

1. `preflight-01.json`：只读 P4 原生 USB，旧镜像、音量 100%、codec 身份／未静音、FAULT valid=0。
2. `music-current-volume-01.json`：两次旧音乐请求均执行，PA 播放期打开、结束关闭，UI 序列递增、错误 0、同一 boot；临时读取麦克风电平，结束停止，未保存原始录音。电平没有证明声学合格；物理结论来自用户「音乐能听到，但很小」。
3. `preview-level-red.log`：在旧 7000 素材上新增电平断言失败；原失败证据保留。
4. `generate-level.log`、`pcm-measurements.json`、`rendered-pcm-levels.log`：新素材与真实 renderer 电平，不是设备声压。
5. `asset-tests.log`：4 项素材／来源／完整性测试通过；`audio-tests-green.log`：音乐 renderer、语音 worker、app 音频适配器 3 项通过。
6. `audio-concurrency.log`：生产 BSP 并发回归通过；补齐现有语音 DMA 所有权的测试状态，验证语音保留所有权时，旧音乐／提示音不能覆盖队列。不改弱生产仲裁。
7. `build.log`：产品 9 步增量构建通过，没有 clean 或全 SDK 重编。

## 上板验收

- 使用 `tools/meoave.py hardware --cycles 1 --restarts 0`，仅烧 P4，不操作 C5／下载三脚；结果记录于 `usb-acceptance-01.json`。
- `usb-acceptance-01.json`：三段镜像烧写、Hash 校验、受控启动、新 ELF 身份、USB／供电保持／触摸通信通过；没有额外程序复位，未操作 C5。
- `music-acceptance-01.json`：60%／0%／100% 三次试听的软件判据通过，DAC 分别读回 B0/B0、00/00、BF/BF；重复启动拒绝、播放退出、PA 关闭及原音量 100% 恢复通过，同一 boot、FAULT valid=0。软件判据不代替真实听感。
- 用户确认「变大了，但仍偏小」「显示正常，无花屏」。因此记录为数字电平改善、显示实屏通过，响度仍未达到用户预期；没有单独得到失真评价。
- 用户随后要求「就这样吧，别改了，尽量大一点」。按此停止进一步增益／素材／硬件修改和试听，保留已经烧录的增强素材版本及原 100% 音量；不将收尾等同于响度验收通过。
- 仅本地音乐素材低电平修订，不宣称完整音频标定、物理最大功率、TTS 部署或完整 AI 对话已完成。

## 增益资料核对（只读，无固件／硬件修改）

- NS4150B 厂商手册 V1.1 第 7 页 §9.9 给出内部反馈电阻 240 kΩ、差分增益 `Av = 240 kΩ / Rin`。用户提供的 2026-11-06 网表中 R127／R128 各为 100 kΩ，理论增益为 2.4 倍（约 7.6 dB）。这不是实物阻值或实际输出电压测量，不能据此断言电阻选错或要求改阻值。
- 网表为 ES8389 左声道 LOUTP／LOUTN 接功放 INP／INN，不是左右声道同相相减。每支串联 1 µF 与 100 nF，忽略其他阻抗时等效约 90.9 nF，结合 100 kΩ 理论高通截止约 17.5 Hz；这不足以单独解释全频声音偏小。
- ES8389 厂商手册 Revision 6.0 第 11 页给出 AVDD=3.3 V 时差分满幅输出典型值 1.85 Vrms。实际功放供电接 VSYS，电压、负载和声压均未测，不能把器件标称功率当成本机实际功率。
- 核对 Linux／Espressif 官方 ES8389 驱动后，未找到足以支持本轮安全提高模拟输出增益的依据；维持现有配置，不写未知寄存器。取得的源码、来源地址、哈希及相关手册页渲染保存在本轮本地证据目录。
