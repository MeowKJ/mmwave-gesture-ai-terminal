# UI 与音频交互修订

日期：2026-11-12。面向 2 英寸 460×460 **方屏**；不改显示初始化、触摸引脚、电源保持、原生 USB 下载和单次 180° 旋转。

## 产品行为

- **AI：** 纯黑画布和黑白眼睛，不显示电量、Wi-Fi、文字或按钮。轻触进入 App 页。
- **App 主页：** 保持两个核心入口和两侧露出的卡片；顶部显示真实 Wi-Fi 状态和单行电量。名称区也可拖动，滑动不触发应用。
- **关机：** 保持 1.5 秒长按防误触，随后倒数 3 秒（总按住约 4.5 秒）。黑底、细环连续收拢、44px 数字、28px「松手取消」，取消后恢复原页面。减少动态效果下仅按秒离散更新，无闪烁、光晕或淡入。
- **麦克风：** 无开关。进页排队启动采集，离页（包括滑动返回）排队停止。左右通道电平独立显示；灵敏度调节 ES8389 PGA 0..14 档，显示归一化百分比，不是测得的声压或概率。增益通过 `mic_g` 保存到 NVS，保留已校准的输入路由。旧 `mic_test` 存储不再启用采集。
- **扬声器：** 只保留音量卡片和「试听」。约 1.69 秒原创脉冲波 8-bit 旋律，加短起落包络和结尾静音。使用当前 DAC 音量，不临时切到固定测试音量；0% 仍是静音。后台播放，期间禁用重复请求，失败按需反馈。工程自检命令保留，但不出现在产品页面。
- **排版：** 黑底加青色/琥珀点缀，正文 28px、关键数值 44px；主要按钮至少 64px。字体更新只重新生成 28px 子集。

## 十项问题闭环

1. 麦克风回调移出 Wi-Fi 条件编译，音频操作排队，不在 GUI 回调阻塞。
2. 密码请求被拒绝时保留缓冲和掩码，在密码页本地提示；接受或离页才清理。
3. 退格重置多击组合态；模式和明文切换提交当前字符。
4. 数字、大小写、分组符号支持全部 95 个可打印 ASCII，含空格；允许空密码交给连接适配器处理开放网络。
5. 六条已缓存网络均可垂直滚动到达；触摸/惯性期间冻结行身份，避免列表刷新点错 SSID。
6. 保存失败用真实创建的瞬时提示显示，不再写入空指针标签；正常保存无常驻说明。
7. App 固定名称区拖动传递到轮播并吸附，不因滑动误启动。
8. 减少动态效果会停止网络提示的无限透明度动画，并冻结关机环的连续动画。
9. AI 状态移到 App 页，百分比不追加 `+`，100% 不换行；未知电量隐藏整个电池组件。
10. 扬声器页去除 WAIT/PASS/MCLK/MIC/VOL 等工程信息及回环按钮。

另补：关机取消请求遇到 GUI 锁竞争会保留重试；关机打断返回手势/转场时取消旧动画，避免取消关机后页面偏移。音频状态只在成功取得 GUI 锁后确认已投递。

## 可重复离线验证

已有桌面 CMake 构建目录时：

```powershell
cmake --build firmware/p4_gesture/tests/desktop/build -j8
ctest --test-dir firmware/p4_gesture/tests/desktop/build --output-on-failure -j2
python tools/meoave.py test
python tools/meoave.py build --profile product
```

首次需用本机原生 GCC/G++/Ninja 配置 `tests/desktop`（不是 ESP 交叉编译器）。CTest 注册以下入口；并发测试还需要可发现的 Python 3 和 pthreads：

- `ui.visual`：真实 LVGL 页面、字库/图标像素、旋转触摸、轮播、返回和呼吸。
- `ui.interaction`：密码拒绝与全部 ASCII、退格、六行网络手势、保存反馈、麦克风进出与增益边界、试听音量/静音/防连点、减少动态静态像素、3 秒环和转场中断。
- `audio.preview`：生产用同一采样器，检查立体声、包络、精确时长、末尾静音及分块不改变采样。
- `model.state`：现有模型回归。
- `audio.adapter`：实际 app 适配器配合假依赖，验证连续同错误快速失败仍解除试听忙碌、GUI 锁竞争、音量应用失败不播放、增益保存防抖及关机取消重试。
- `audio.concurrency`：生产 BSP 采集/播放段与完整自检模块配合 pthread 假 RTOS，验证阻塞读期间的停止/暂停、反复进出复用同一个采集任务，以及试听与工程音频的双向互斥和失败释放。

PPM 快照保存在桌面构建目录 `artifacts/visual`、`artifacts/interaction`；可选给 `meoave_interaction_test` 传入其他已存在目录。测试不访问串口、不烧录、不复位 C5。先跑测试、后做最终增量固件构建。

## 验收边界

桌面预览来自**同一套 LVGL C 代码**，不是设计稿；桌面运行时间不等于屏幕 FPS。音频软件测试只验证样本和控制链，不能证明实际扬声器响度/音质、麦克风噪底或真实增益效果。

本轮需上板补验：音量 0/30/70% 试听、连续点击、边播边调音量；正常声音下比较低/高麦克风灵敏度；程序复位后增益/音量保持；长按 3 秒倒数中途松手；在设置返回手势中长按关机；AI 无状态，App 有真实状态。不得把已构建镜像当作已下载或实屏通过。

独立复查另修复四项：麦克风改为常驻休眠任务，不强杀 I2S 读任务；试听状态增加请求代次，快速重复失败也会确认完成；输入增益只走设置保存防抖，校准路由另行等待稳定；试听与自测/校准/工程测试音共享输出租约，不能互相抢音量、DMA 和功放。未把这些离线并发验证当作硬件长期稳定性结果。

初版结果：197 项 Python 回归、6 个 CTest 入口、产品固件编译及链接入口检查均通过。模拟构建测试的签名写入已隔离到临时目录，避免污染真实构建缓存；增量构建可以跳过配置，不再因测试导致全量编译。

- 对每个候选地址连续两次读取 ES8389 ID；拒绝只有 ACK、`FF`、NACK 或不稳定身份的候选。

- `AUDIO HEALTH <token>` 汇总实时只读身份、配置、音量和单端路由；试听 worker 记录真实返回值。
- `UI VOLUME <0..100>` 和 `UI PREVIEW` 复用真实设置/试听路径，`MEO:UI_AUDIO` 提供音量、灵敏度及播放请求代次，供自动验收使用，不出现在产品页面。
